AI coding agents are getting better but generating code is only one part of software engineering. Breaking down work, coordinating agents, testing changes, and maintaining control over the development process are equally important.

That's why I'm building **[Orxest](https://github.com/orxest/orxest)** - an open-source project exploring how to orchestrate AI coding agents into a software development workflow.

The idea is to move beyond one-off prompts and individual coding sessions toward a system where specialized coding agents can collaborate on well-defined tasks, supported by the right workflows and engineering practices.

Orxest is an ongoing experiment in what an AI-driven software factory should look like. I'm sharing the architecture, implementation, and lessons learned as it evolves.

If you're interested in agentic software engineering, I'd welcome your feedback and ideas.
